Introduction & Architecture

Welcome to the SHARED AI SERVICE API Documentation. This unified multi-tenant AI service powers intelligent capabilities across OWL LMS, HR Corner, and enterprise applications.

System Architecture

The Shared AI Service is built on FastAPI, lightweight LLM inference (llama-server / Qwen2.5), Qdrant vector database, and faster-whisper transcription engine.

Core Capabilities

Unified Chat & MCP Tools

Multi-tenant conversational agent with access to 10+ LMS & RAG tools for personalized assistance.

Knowledge Management

Categorized document ingestion, fast vector retrieval, summary generation, and management.

PDF & Video RAG

Automated PDF parsing and local Whisper audio/video transcription with hybrid semantic search.

Personalized Recommendations

6-factor weighted recommendation engine for courses, content, and learning playlists.
