Quick Start Guide

Get up and running with the Shared AI Service in 3 simple steps.

Step 1: Obtain Authorization API Key

All client applications interacting with the service must supply an API key in the X-API-Key request header.

  • OWL LMS API Key: owl-secret-api-key
  • HR Corner API Key: hr-corner-secret-api-key
  • Master Shared AI Key: dev-shared-ai-key-change-in-production

Step 2: Check Service Health

Verify that the service is running and dependencies (Qdrant & LLM backend) are healthy:

cURL 
curl -X GET "http://localhost:8000/api/v1/health"

Step 3: Send Your First Chat Request

Send a message to the Unified AI Chat endpoint for OWL LMS:

cURL 
curl -X POST "http://localhost:8000/api/v1/chat" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: owl-secret-api-key" \
  -d '{
    "application": "owl",
    "user_id": 1,
    "message": "Rekomendasikan kursus Python untuk pemula."
  }'
