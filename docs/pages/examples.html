1. Python (requests & httpx)

Integration using Python's requests library for multi-tenant chat:

Python 
import requests

BASE_URL = "http://localhost:8000/api/v1"
HEADERS = {
    "Content-Type": "application/json",
    "X-API-Key": "owl-secret-api-key"
}

def ask_ai_agent(user_id: int, message: str):
    url = f"{BASE_URL}/chat"
    payload = {
        "application": "owl",
        "user_id": user_id,
        "message": message
    }
    response = requests.post(url, headers=HEADERS, json=payload)
    response.raise_for_status()
    return response.json()

if __name__ == "__main__":
    res = ask_ai_agent(user_id=42, message="Apa saja rekomendasi modul pembelajaran minggu ini?")
    print("AI Answer:", res.get("answer"))

2. JavaScript (Fetch API / Node.js)

Integration using modern JavaScript async/await for PDF RAG ingestion:

JavaScript 
async function uploadPdfDocument(fileInput, documentId, title) {
  const formData = new FormData();
  formData.append("file", fileInput.files[0]);
  formData.append("application", "owl");
  formData.append("document_id", documentId);
  formData.append("title", title);

  const response = await fetch("http://localhost:8000/api/v1/rag/documents/upload", {
    method: "POST",
    headers: {
      "X-API-Key": "owl-secret-api-key"
    },
    body: formData
  });

  if (!response.ok) {
    const errorData = await response.json();
    throw new Error(`Upload failed: ${errorData.error?.message || response.statusText}`);
  }

  const result = await response.json();
  console.log("PDF Upload Success:", result);
  return result;
}
