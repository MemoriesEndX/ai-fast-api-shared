Standard Error Code Catalog

The Shared AI Service returns structured JSON error responses with consistent HTTP status codes and machine-readable error codes.

Error Response Format

Standard Error Payload 
{
  "error": {
    "code": "ERROR_CODE_STRING",
    "message": "Human readable description of the error.",
    "request_id": "c76f6b5b-..."
  }
}

Error Code Dictionary

HTTP StatusError CodeCause / Solution
400 INVALID_REQUEST Payload validation failed, missing required fields, or payload size exceeds maximum limit.
401 UNAUTHORIZED Missing or invalid X-API-Key header. Ensure proper API key is provided.
403 TENANT_ACCESS_DENIED Client application key mismatch with request application field (e.g. OWL key requesting HR Corner data).
404 RESOURCE_NOT_FOUND Requested document, article, or endpoint does not exist.
413 PAYLOAD_TOO_LARGE Uploaded file exceeds maximum size limits (PDF > 25MB, Audio > 50MB, Video > 250MB).
429 RATE_LIMIT_EXCEEDED Client application has exceeded the maximum request rate per minute limit.
503 AI_SERVICE_UNAVAILABLE Upstream LLM backend (llama-server) or Qdrant vector database is offline or not ready.
